MyNAV — OSD Layout Tool

Paste an INAV diff / dump, arrange the elements of each layout visually, copy the osd_layout lines back into the CLI. Lines are osd_layout <layout> <item> <column> <row> <V|H>, as printed by src/main/fc/cli.c.

Select an element on the right, then click a grid cell to move its top-left there. Red = overlap. Hidden elements (H) are not drawn.
